# 住户功能

## 一、功能概述：

          住户信息是玩家鉴别真实性的一大关键要素，囊括了图片资料、职业背景、身份证件与个人体征等核心信息。这些数据于每场游戏开局时，均从“好人表”中系统筛选而出。为了便于玩家迅速查证，每个住宅单位均配以明确的房间编号标识，既确保了查询效率，又维持了游戏的流畅性与沉浸感。

## 二，功能逻辑

### 功能内容（可配置）

1.  每局开始前会从生成的X个好人，放入好人表，从中挑选“X”住户外出准备回来，比如本局10个NPC，6个好人，从固定的住户10人中挑选6人出来。
    
2.  楼层目前固定为3层，玩家点击后弹出二级弹窗，里面显示当前楼层的信息。
    
3.  住户信息，从开局DNA表中提取。
