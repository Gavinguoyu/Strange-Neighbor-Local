# 报警功能

## 一、功能概述：

       报警是用于玩家点击后将NPC抓走功能，玩家可以将任意NPC点击报警抓走，无论NPC是好人还是 **【伪人】** 均可。区别在于后续统计分数上，抓走好人不会得到如何分数

## 二，功能逻辑

### 功能内容（可配置）

1.  按键可点击，并且有点击效果。
    
2.  点击后会弹出对话框，内容固定。
    
3.  对话内容（感谢您提供线索，我们将人带走调查。）
