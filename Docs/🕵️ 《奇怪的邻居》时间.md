# 界面左上方图标，作为时间功能区域

## 一、功能概述：

          玩家在游戏中可实时查看当局剩余时间。待计时结束，该局游戏即告完成，系统将自动跳转至结算界面。

## 二、功能内容（可配置）：

1.  **基础计时设定**：~~当局游戏时长预设为5分钟，此参数可根据实际需求灵活调整。~~调整计时机制为晨至暮期间，依NPC交互进展时光推移。具体而言，每达成或婉拒与一定数量的NPC互动，时间往前推动，直到时间达到傍晚，最后一个NPC结束后
    
2.  **时间预警机制**：当剩余时间仅剩2个NPC时，系统将在相应图标处予以显著提示，以提醒玩家把握最后阶段的游戏策略与行动。
