# 今日访客单

## 玩家点击今日访客单，弹出弹窗

1.  今日访客界面包含信息如下（需要可配置）
    
    1.  NPC照片，显示当局可能会出现的NPC。
        
    2.  NPC昵称
        
    3.  NPC所住的房间号
        
2.  今日访客单内的信息绝对正确，供玩家查询，帮其找出 **【伪人】**
    
3.  点击叉关闭或者点击空白区域关闭界面
    

## 美术资源

1.  今日访客单图标x1
    
2.  今日访客单弹窗x1
    
3.  界面弹出动效
