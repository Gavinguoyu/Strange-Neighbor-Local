# 检查功能

## 一、功能概述：

        为了增强玩家体验与交互便捷性，系统特设一项功能：当场景中的NPC未主动展示特定文档时，玩家可通过点击互动按钮，触发一个二级界面。此界面罗列了数项核心查询选项，包括人物的身份证信息、外观特征描述、入场许可申请状况，以及确认其是否列入今日准入名单。若所查询项目当前未予显示，则系统将引导玩家向NPC发起相关询问。

一旦玩家选取某项查询，该辅助界面随即隐去，顺势衔接NPC的对话流程。NPC将根据玩家的选择，以符合其角色背景及场景逻辑的语言，直接回应所提问题。对话界面在最后一个字显示后，停留“X”秒，对话框消失。
