# 项目协作宪法 (Project Constitution)

## 第一条：基本原则
1. **DDD原则**：无文档，不开发。
2. **单一数据源**：看板是唯一进度标准，资产表是唯一路径标准，字典是唯一数据标准。
3. **角色隔离**：策划不写代码，程序不改设计，PM 只管流程。

## 第二条：开发规范
1. **分包原则**：大任务必须拆分为 UI -> 逻辑 -> 集成。
2. **UI 盲区免责**：涉及坐标和层级的代码，AI 必须输出 [人工校对指南]。
3. **小白保护**：程序开发完成后必须提供手把手的 Cocos 编辑器操作指南。

## 第三条：文档标准
每个功能必须包含：
- `📘 配置指南.md` (零基础教程)
- `📋 快速配置清单.md` (精简版)
- `🎨 节点层级结构图.md` (架构图)
