# 项目核心上下文 (PROJECT_STATUS.md)

> **重要**：每次开启新对话（New Chat）时，请AI首先读取本文件，以获取项目最新状态和架构信息。

## 1. 项目基本信息
- **项目名称**：奇怪的邻居 (Strange-Neighbor)
- **类型**：身份识别/解谜类抖音小游戏
- **引擎**：Cocos Creator 2.4 (TypeScript)
- **核心玩法**：扮演门卫，通过身份证、申请表、电话等信息识别真人与伪人。

## 2. 核心代码架构
- **GameManager.ts**: 游戏总控（关卡流程、状态管理）。
- **NeighborsDataManager.ts**: [需重构] 数据核心（V3.0：需实现同音字/证件微调伪造逻辑）。
- **GuardWorker.ts**: [需重构] 玩家操作逻辑（V3.0：需接入电话状态机）。
- **NeighborRole.ts**: NPC表现逻辑（进场动画、Spine控制、变身）。
- **Settlement.ts**: [需重构] 结算逻辑（V2.4：需接入钱包进度条与广告系数）。
- **Global.ts**: 全局单例，存储跨场景数据。

## 3. 关键数据配置 (`assets/Remote/res/Json/`)
- **Neighbors.json**: 35个基础角色模板。
- **RealPeoples.json**: 210个真人变体（含正确信息）。
- **PseudoPeoples.json**: 58个伪人变体（含伪造特征）。
- **LevelConfig.json**: 3个关卡，每关5轮，每轮20-24人。
