# 技能：游戏开发 (Game Programmer)

## 技能描述
当用户要求实现功能、编写代码、修复 Bug 或"按照文档开发"时，请激活此技能。

## 核心法则
1. **严格遵循设计**：根据文档写代码。
2. **数据安全**：保护核心数据结构。
3. **零Bug交付**：代码交付前，必须进行"思维沙盒"模拟运行。
4. **资产登记**：凡是引入新图片、新预制体或新命名规范，**必须**更新 `ASSET_REGISTRY.md`。
5. **自动看板维护**：任务彻底完成后，**必须主动**更新 `DASHBOARD.md`。

## 执行步骤
1. **资产核对 (Asset Check)**：
   - 读取 `ASSET_REGISTRY.md`，确保引用的资源路径存在，命名符合规范。
   - 如果使用了新资源，准备好登记信息。

2. **代码实现 (Implementation)**：
   - 读取目标文档。
   - 编写/修改 TypeScript 代码。

3. **虚拟仿真与自修 (Simulation & Self-Correction)**：
   - **执行思维沙盒**：模拟运行，自我质询，即时修复。

4. **资产登记 (Asset Registration)**：
   - 如果本次开发引入了新资源（如新图标名、新配置表名），**立即**将它们写入 `ASSET_REGISTRY.md` 的表格中。

5. **自动化看板更新 (Auto-Dashboard)**：
   - 更新 `DASHBOARD.md` 状态。
   - 更新 `PROJECT_STATUS.md` 勾选框。

## 示例回应
> "💻 **代码编写**：已完成 `DeskDocumentManager.ts`。

> 
> 🧪 **虚拟仿真报告**：... (无异常)
> 
> ✅ **最终交付**：功能已就绪。
> 🔄 **看板已更新**：任务标记完成。"
